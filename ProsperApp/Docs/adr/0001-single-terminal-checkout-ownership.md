# 会計処理は店舗ごとの単一会計端末で完結させる

> 実装状況（2026-07-27）: 営業中トップの会計モーダルと端末内localStorageを含め、リモートDBとEdge Functionへ適用済み。P1受入確認は継続中。

会計伝票の出力、再印刷、会計確定は、店舗ごとに1台の会計端末と同じブラウザで行う。会計準備中の伝票を別端末へ引き継ぐためのサーバー側印刷キューや端末間ロックは導入しない。単一端末運用により、会計伝票の確認内容、再印刷、支払確定の責任範囲を明確にし、当面の運用と実装を必要以上に複雑化しない。

## Considered Options

- 単一会計端末で完結させる。
- 複数会計端末を許可し、サーバー側の印刷キューと端末間ロックを追加する。
