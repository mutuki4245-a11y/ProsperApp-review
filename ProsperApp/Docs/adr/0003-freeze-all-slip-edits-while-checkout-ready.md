# 会計準備中の伝票はすべての編集を止める

> 実装状況（2026-07-20）: `checkout_ready` と各更新RPCの `open` 限定としてソース実装済み。リモートDB適用は未実施。

`checkout_ready` の伝票では、注文や金額に直接影響する操作だけでなく、客名、メモ、個別退店時刻を含むすべての伝票編集を禁止する。会計伝票で客が確認した内容と会計確定時の内容を一致させるため、変更が必要な場合は先に会計準備を解除して伝票を `open` に戻す。

## Considered Options

- 会計準備中はすべての伝票編集を止める。
- 金額に影響しない編集だけを例外として許可する。
