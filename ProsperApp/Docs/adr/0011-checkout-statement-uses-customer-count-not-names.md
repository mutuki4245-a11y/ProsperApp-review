# 会計伝票は客名ではなく客数を出力する

> 実装状況（2026-07-20）: `checkout-statement-v1` のSQL生成、会計確認画面、会計伝票SIIレイアウトにソース実装済み。リモートDB適用とEdge Functionデプロイは未実施。

会計伝票は席での会計内容確認用であり、店舗表示名、卓番、入店時刻、退店時刻、客数を出力する。客数は取消客を除く客行数であり、途中退店した客を含める。顧客名、`checkout_id`、`slip_id`、`slip_no` は内部識別にとどめ、`checkout-statement-v1` の印字データの表示項目と紙面には含めない。指名キャスト名・種別とバック対象キャストも、会計確認画面だけで内部確認し、紙面には含めない。

## Considered Options

### 客名を併記する

誤卓防止に使えるが、会計伝票に必要な情報ではない。客名は内部運用の識別情報であり、紙面へ出す範囲を不必要に広げる。

### 客情報を出さない

人数と利用時刻の確認ができず、席での会計内容確認に必要な文脈が不足する。

### 決定案

会計伝票の客情報は客数だけとし、客名は出力しない。
