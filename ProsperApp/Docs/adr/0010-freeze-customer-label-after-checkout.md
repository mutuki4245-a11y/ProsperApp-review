# 会計後の顧客名を確定値として扱う

> 実装状況（2026-07-27）: `open` 限定の顧客名更新をリモートDBへ適用済み。P1受入確認は継続中。

顧客名は注文端末と締め時のキャスト売上額調整一覧で伝票を識別する内部情報であり、領収書の宛名ではない。`store.update_slip_customer_label` と画面の更新入口は `open` の伝票だけに限定し、`checkout_ready` と `checked_out` の顧客名は変更しない。訂正が必要な会計準備中伝票は会計準備を解除してから行い、会計確定後は会計取消で営業中に戻した場合だけ変更できる。

## Considered Options

### 会計済み後も顧客名だけ訂正可能にする

現行はこの例外を持つが、締め時に参照する伝票の識別表示が会計確定後に変わる。会計済み伝票の内容を確定値として扱う方針と一致しない。

### 顧客名を領収書の宛名として保存する

宛名は印刷時の任意入力であり、会計データへ保存しないという領収書方針と衝突する。

### 決定案

顧客名は `open` 中の伝票情報としてだけ更新できる。`checkout_ready` と `checked_out` では確定値とする。
