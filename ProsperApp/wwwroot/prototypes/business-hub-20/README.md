# 営業中ハブ20件表示プロトタイプ

> PROTOTYPE — THROW AWAY。比較専用で、DB更新や保存は行いません。

「20件のopen伝票、全18卓の満席、A1・B3に各2組がいる状態を、どの情報構造なら把握しやすいか」を比較するプロトタイプです。

PowerShellから次の1コマンドで開けます。

```powershell
Start-Process .\wwwroot\prototypes\business-hub-20\index.html
```

画面下の左右ボタン、またはキーボードの左右キーで案を切り替えます。URLの `?variant=A`、`?variant=B`、`?variant=C`、`?variant=D` でも直接開けます。

- A — 高密度台帳：20件の詳細を一列で高速走査
- B — 卓ボード：18卓を3段で俯瞰し、選択した卓だけ詳細表示
- C — 滞在タイムライン：長時間滞在と同卓複数組を時間軸で把握
- D — 夜レジ風伝票パネル：伝票カードを卓番順に並べ、カテゴリ線と会計済みアコーディオンで整理

検索、卓ジャンプ、卓詳細パネル、D案の絞り込みと会計済みアコーディオンは画面内だけで動作します。
