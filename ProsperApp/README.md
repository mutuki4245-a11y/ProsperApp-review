# ProsperApp Review

This branch is prepared for UI and workflow review.

- Authentication is disabled by `Review:DisableAuthentication`.
- Supabase access is replaced by in-memory mock data through `Review:UseMockData`.
- Google Drive preview is replaced by a local mock response.
- Receipt printer integration is disabled.

The review app is intended for functional walkthroughs only. Data changes are kept in memory and are reset when the app restarts.

Included documents:

- `docs/requirements-definition.md`
- `docs/system-specification.md`
